IEA Data Scraping and Visualiation
Last Updated 26th March 2026 

This folder contains the following files 
1. IEA Data Scraper - Takes countries and web pages and scrapes data to store as simple organised datatsets by country. This file is saved as main.py 
2. Visualisation code for all the R graphs. This file is saved as Final_VisualCode.R It is seperated using lines of #s between each graph. The graphs can be referred to the mani-visuals folder. They are saved as v1, v2 etc. each corresponding to the respective # in the R file. For example, all graphs with v2 correspond to the second chunk, i.e., after the first set of #s and before the 3rd. 
3. mani-data contains the scraped data organised by country 
4. mani-visuals contains the visuals organised as v1,v2..., this uses the same logic as above
5. pyproject.toml very quick overview of the python and package version used 
6. uv.lock contains the exact snapshot of how the code was run, i.e., all version relevant details. Can use uv sync to get the exact same version, ready to replicate. 
7. README.md contains a quick guide to the whole thing to help later, if needed

📊 Overview
This repository provides a comprehensive pipeline for extracting energy data from the International Energy Agency (IEA) and generating high-quality analytical visualizations. The project is designed for high reproducibility, utilizing uv for Python environment management and structured R scripts for data viz.

📂 Repository Structure
🐍 Python Data Extraction
main.py (IEA Data Scraper): The primary scraping engine. It processes a list of target countries and web pages to extract raw data into organized datasets.

mani-data/: Directory containing the scraped datasets, meticulously organized by country for easy access.

📈 R Visualization
Final_VisualCode.R: A consolidated R script containing all visualization logic.

Note: The script is partitioned using # comment blocks. Each block corresponds to a specific visualization set.

mani-visuals/: Stores the output graphics.

Naming Convention: Files are saved as v1, v2, etc. These correspond directly to the code chunks in the R file (e.g., v2 files are generated by the second block of code).

⚙️ Environment & Reproducibility
pyproject.toml: Provides a high-level overview of Python requirements and package dependencies.

uv.lock: A precise cryptographic snapshot of the environment.

README.md: This guide.

🚀 Getting Started
1. Replicate the Python Environment
This project uses uv for lightning-fast, reproducible dependency management. To sync your local environment with the exact versions used during development, run:

Bash
uv sync
2. Running the Scraper
Execute the main script to begin the data collection process:

Bash
python main.py
3. Generating Visuals
Open Final_VisualCode.R in your R environment (such as RStudio). Ensure your working directory is set to the project root so the script can correctly locate the data in mani-data/ and export graphics to mani-visuals/.

🛠 Tech Stack
Scraping: Python (see pyproject.toml for specific libraries)

Environment Management: uv

Analysis & Visualization: R (Tidyverse)

# Scraping Archive

#### Author: Vaibhav Agarwal

This repository serves as an archive for various web scraping and data analysis projects. 

It is designed to store source code, processing scripts, and final visualizations from different data extraction tasks.  

## Current Projects
### IEA Data Scraping and Visualization

Description: A pipeline for extracting energy data from the International Energy Agency (IEA) website.  
Components: Includes a Python-based scraper, R scripts for analytical visuals, and an environment lockfile for full replication.  
Directory: /IEA_Scraping 
Repository Goal: The primary objective of this archive is to maintain a clean record of scraping logic and data workflows for future reference and reproducibility across different domains.
